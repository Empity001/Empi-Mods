Catch Roulette

In development

Throw a Poké Ball and watch your catch chance spin on a slot machine roulette.

14%

This is a demo. In the game, the server picks the result.

What it does

When you throw a Poké Ball, a roulette of 100 slots opens on your screen. If the chance is 14%, 14 slots are lit.

Cobblemon decides whether you catch the Pokémon, as it always does. The roulette is only the show: it stops on a lit slot when you catch it, and on an unlit slot when it escapes.

It works in battles and when you throw a ball at a wild Pokémon.

Install

You need

  • Minecraft Java Edition 1.21.1
  • Fabric Loader
  • Fabric API
  • Cobblemon 1.8 or newer for Fabric

Then

  1. Download the Catch Roulette jar.
  2. Put it in the mods folder.
  3. Do the same on the server.

There is no download yet. This page will link to Modrinth when the first version is out.

Good to know

  • It needs to be installed on the server too, so every player on the server sees the same result.
  • The roulette never changes your chances. It only shows what Cobblemon already decided.
  • Other mods that change how captures work may show a different chance.
