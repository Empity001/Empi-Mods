Catch Roulette

Throw a Poké Ball and a roulette of 100 slots appears. Your catch chance decides how many slots are lit, and the roulette stops on a slot that matches the real result.

How Catch Roulette works

  1. Throw

    You throw a Poké Ball at a Pokémon, in a battle or in the wild.

  2. Roll

    A roulette of 100 slots opens. A 14% chance lights 14 slots.

  3. Land

    The server already decided the capture. The roulette stops on a slot that matches it.

Install

You need

  • Minecraft Java Edition 1.21.1
  • Fabric Loader
  • Fabric API
  • Cobblemon 1.8 or newer for Fabric

Then

  1. Download the Catch Roulette jar.
  2. Put it in the mods folder.
  3. Do the same on the server.
